docker 镜像加速

概述

国内经常会遇到镜像拉不下来的问题，下面提供几个解决方案

设置 docker 镜像源

设置步骤

  1. 打开或创建 Docker 配置文件 /etc/docker/daemon.json。
{
    "registry-mirrors": ["https://docker.1ms.run"]
}
  1. 保存文件并重启 Docker 服务：
sudo systemctl daemon-reload
sudo systemctl restart docker
  1. 验证
docker info

可以看到 Registry Mirror 中包含设置的镜像地址

可用镜像源

  • https://docker.1ms.run
  • https://docker.m.daocloud.io （来自 https://github.com/DaoCloud/public-image-mirror）

设置 docker 系统代理

步骤

修改 systemd 配置文件的 Env 环境参数，加上 https_proxy 和 http_proxy 即可
