常用命令

清除 docker 日志

sudo bash -c " cat /dev/null > /var/lib/docker/containers/f0bce033973c66831322f48753512845b74e64aeeb9aea12285d62a50ae8b401/f0bce033973c66831322f48753512845b74e64aeeb9aea12285d62a50ae8b401-json.log

上述清除会立即释放空间；否则删除后需要重启容器才会释放呢

查看镜像的层

# docker inspect <image_name_or_id>
...
"RootFS": {
    "Type": "layers",
    "Layers": [
        "sha256:1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef",
        "sha256:abcdef1234567890abcdef1234567890abcdef1234567890abcdef1234567890"
    ]
}
...

查看镜像的构建历史

# docker history <image_name_or_id>
MAGE          CREATED        CREATED BY                                      SIZE      COMMENT
1234567890ab   2 weeks ago    /bin/sh -c #(nop)  CMD ["/bin/bash"]            0B
abcdef123456   2 weeks ago    /bin/sh -c apt-get update && apt-get install   100MB

dive 工具可以提供更深入的 docker 镜像分析 https://github.com/wagoodman/dive/
