curl

认证

在 curl 命令中，-u username:password 参数用于进行 HTTP 基本认证（Basic Authentication）。具体来说，curl 会将 username:password 进行 Base64 编码，并将其添加到请求头中的 Authorization 字段。

例如，如果你使用 curl -u username:password ``https://harbor.example.com/api/v2.0/projects，curl 会生成如下的请求头：

Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=

其中，dXNlcm5hbWU6cGFzc3dvcmQ= 是 username:password 的 Base64 编码结果
