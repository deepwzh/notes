文件系统工具

空间清理

ncdu

du 的升级版，用于以 GUI 的形式展示磁盘的空间占用情况

建议使用 2.0+ 版本，避免删除时没有确认的问题

安装

sudo apt install ncdu

文档： https://dev.yorhel.nl/ncdu/man

他还支持一个 Web UI，来展示文件树结构

https://ncdu.blicky.net/
