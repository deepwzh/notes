问题排查

磁盘分析工具

ncdu

查看当前正在使用的读写句柄

lsof +L1

清除正在占用文件句柄的空间

sudo truncate -s 0 path

如果这个文件已经删除过了，可以通过 lsof +L1 找到这个文件的 fd 和对应进程的 pid，然后进行

sudo truncate -s 0 /proc/pid/fd/xxx
