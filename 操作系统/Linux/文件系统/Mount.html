Mount

常用参数

-t 要挂的文件系统类型

在 Linux 系统中，mount 命令的 -t 参数用于指定要挂载的文件系统类型。如果不指定该参数，系统会尝试自动检测设备或文件的文件系统类型，但显式声明类型可以避免兼容性问题或错误。

常用文件系统类型示例

以下是一些常见的文件系统类型，适用于不同的设备和场景：

  1. 本地存储设备

    • ext4：Linux 默认的日志文件系统（如挂载硬盘分区：mount -t ext4 /dev/sdb1 /mnt/data）。
    • ntfs：Windows 的 NTFS 文件系统（需安装 ntfs-3g 包支持）。
    • vfat/fat32：兼容 USB 设备或旧版 Windows 的 FAT 文件系统。
    • iso9660：光盘镜像文件的标准格式（如挂载 ISO：mount -t iso9660 -o loop image.iso /mnt/iso）。

  2. 网络文件系统

    • nfs：网络文件系统（如挂载远程共享：mount -t nfs 192.168.1.100:/share /mnt/nfs）。
    • cifs/smbfs：Windows 网络共享（需 Samba 支持，如 mount -t cifs -o username=user //server/share /mnt/smb）。

  3. 虚拟/特殊文件系统

    • tmpfs：基于内存的临时文件系统（如 mount -t tmpfs -o size=1G tmpfs /mnt/tmp）。
    • proc：内核和进程信息的虚拟文件系统（通常挂载到 /proc）。
    • drvfs：WSL（Windows Subsystem for Linux）中用于挂载 Windows 驱动器的虚拟文件系统（如 mount -t drvfs E: /mnt/e）。

  4. 其他类型

    • btrfs：支持快照和压缩的高级文件系统。
    • xfs：高性能日志文件系统，适用于大文件存储。
    • overlayfs：联合挂载文件系统，常用于容器技术。
  • 使用 cat /proc/filesystems 可查看当前系统支持的所有文件系统类型。
  • 部分文件系统（如 ntfs、exfat）可能需要额外安装驱动或工具包。
  • 在 WSL 中，drvfs 是专为访问 Windows 驱动器设计的类型，直接兼容 NTFS/FAT32 格式。
