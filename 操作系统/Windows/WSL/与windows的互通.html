与 windows 的互通

文件系统互通

wsl 可以访问 windows 下的驱动器，具体在/mnt 目录

如果 windows 下新增了驱动器（或者映射的网络位置），可能需要手动进行挂在

手动挂载 windows 驱动器

比如我要挂在 windows 下的 z 盘到 wsl 内，可以使用：

sudo mount -t drvfs z: /mnt/z

更多文件系统类型，可见 Mount
