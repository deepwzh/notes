端口转发

常用于 wsl 的端口转发（因为 wsl 的网络往往没有桥接到网卡上)

如，将 ip 为 172.24.50.48 wsl 的 ssh 服务（端口 22)，转发到 pc 机的 2221 端口上，供外部访问

netsh interface portproxy add v4tov4 listenport=2221 connectaddress=172.24.50.48 connectport=22 listenaddress=* protocol=tcp

查看已经设置的端口映射

netsh interface portproxy show all
